agent-memory · 0.1.1

Agent Memory

Token-aware windowing, summarization, RAG recall, and SQLite persistence for LLM agents — one orchestrator, YAML config, OpenAI-style message packs.

Start

pip install agent-memory

from agent_memory import AgentMemory
mem = AgentMemory.from_config()
mem.add_user("Hi, I'm Alice.")
pack = mem.prepare("Who am I?", system_prompt="Be helpful.")
messages = pack.to_chat_messages()
